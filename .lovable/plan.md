
# Редактирование сообщений вместо отправки новых

## Проблема
Сейчас при нажатии inline-кнопок бот отправляет **новое сообщение** каждый раз. Это засоряет чат множеством сообщений (как видно на скриншоте).

## Решение
Использовать Telegram API метод `editMessageText` вместо `sendMessage` при обработке callback-кнопок. Так бот будет **обновлять то же самое сообщение**, на кнопку которого нажали.

## Что изменится

### Файл: `supabase/functions/telegram-bot/index.ts`

1. **Добавить функцию `editMessage`** -- новый хелпер, который вызывает `editMessageText` API Telegram с `chat_id` и `message_id` исходного сообщения.

2. **Изменить все обработчики команд** (`handleLaw`, `handleProfile`, `handleGiveaways`, `handleTickets`, `handleNews`, `handleHelp`) -- добавить опциональный параметр `messageId`. Если он передан, бот редактирует существующее сообщение; если нет (команда из текста) -- отправляет новое.

3. **Обновить обработку callback_query** -- передавать `cb.message.message_id` в каждый обработчик, чтобы кнопки редактировали текущее сообщение.

### Результат
- Нажатие кнопки "Розыгрыши" -- текст сообщения меняется на список розыгрышей
- Нажатие "Главное меню" -- текст возвращается к меню
- Один блок сообщения, никакого спама
