
# Telegram бот для Hardy Help

## Что будет сделано

Telegram бот на базе grammY framework, работающий через webhook на backend-функции. Три основных модуля:

### 1. Привязка аккаунта
- Команда `/start` с уникальным кодом привязки
- На сайте в профиле появится кнопка "Привязать Telegram" -- генерирует одноразовый код
- Пользователь отправляет этот код боту, и Telegram chat_id сохраняется в профиле

### 2. Уведомления в Telegram
- После привязки аккаунта админы/модераторы получают уведомления прямо в Telegram:
  - Новая заявка на розыгрыш
  - Новая тема на форуме
  - Новый тикет поддержки
- Обычные пользователи получают:
  - Ответ на тикет поддержки
  - Победа в розыгрыше

### 3. Тикеты поддержки из Telegram
- Команда `/ticket Тема сообщения` -- создает тикет прямо из Telegram
- Ответы админов на тикет приходят в Telegram
- Пользователь может отвечать прямо в боте

## Техническая реализация

### Шаг 1: Настройка Telegram Bot Token
- Запросить у пользователя токен бота от @BotFather и сохранить как секрет `TELEGRAM_BOT_TOKEN`

### Шаг 2: Обновить таблицу `profiles`
- Добавить столбец `telegram_chat_id` (bigint, nullable) -- для связи аккаунта с Telegram

### Шаг 3: Создать таблицу `telegram_link_codes`
- `id` (uuid), `user_id` (uuid), `code` (text, unique), `created_at`, `expires_at`
- Одноразовые коды для привязки аккаунта, истекают через 10 минут

### Шаг 4: Edge Function `telegram-bot`
- Webhook-обработчик на grammY framework
- Обрабатывает команды:
  - `/start [code]` -- привязка аккаунта по коду
  - `/ticket [текст]` -- создание тикета поддержки
  - `/help` -- список команд
- Настроить `verify_jwt = false` в config.toml

### Шаг 5: Edge Function `telegram-send`
- Вспомогательная функция для отправки сообщений в Telegram
- Принимает `chat_id` и `text`, отправляет через Telegram Bot API
- Вызывается триггерами базы данных через `pg_net` или другими функциями

### Шаг 6: Триггеры для отправки уведомлений
- Создать функцию `send_telegram_notification()` которая при создании записи в `forum_notifications` проверяет, есть ли у пользователя `telegram_chat_id`, и вызывает edge function `telegram-send`
- Использовать `pg_net` расширение для HTTP-вызовов из триггеров

### Шаг 7: Обновить страницу профиля
- Добавить секцию "Telegram" в профиле пользователя
- Кнопка "Привязать Telegram" -- генерирует код и показывает инструкцию
- Статус привязки (привязан / не привязан)
- Кнопка "Отвязать Telegram"

### Шаг 8: Установить webhook
- После деплоя вызвать Telegram API `setWebhook` с URL edge function

### Файлы которые будут изменены/созданы:
- `supabase/functions/telegram-bot/index.ts` -- новый, основной обработчик webhook
- `supabase/functions/telegram-send/index.ts` -- новый, отправка сообщений
- `src/pages/Profile.tsx` -- добавить секцию привязки Telegram
- SQL миграция -- новые столбцы и таблицы
