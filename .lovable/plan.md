# Новые функции для Telegram бота Hardy Help

## Что уже есть

- `/start` -- привязка аккаунта
- `/ticket` -- создание тикета поддержки
- `/help` -- список команд
- Уведомления о событиях на сайте
- Ответы на тикеты прямо из Telegram

## Что можно добавить

### 1. Поиск законов `/law`

Команда `/law ук 228` или `/law дк 12.1` -- поиск статей по кодексам прямо в Telegram. Бот будет искать в таблице `laws` и возвращать текст найденной статьи.

### 2. Статус профиля `/profile`

Команда показывает информацию о привязанном аккаунте: имя пользователя, роль, количество открытых тикетов, участие в розыгрышах.

### 3. Активные розыгрыши `/giveaways`

Список текущих активных розыгрышей с названием, призом и датой окончания. Со ссылкой на сайт для участия.

### 4. Мои тикеты `/tickets`

Список открытых тикетов пользователя с темой и датой создания. Возможность переключиться на конкретный тикет для ответа.

### 5. Последние новости `/news`

Показать 3-5 последних новостей с сайта (из таблицы `discord_news`).

### 6. Inline-кнопки

Вместо текстовых команд добавить интерактивные кнопки (Telegram Inline Keyboard) для навигации по функциям бота при вводе `/start`.

## Техническая реализация

### Изменения в `supabase/functions/telegram-bot/index.ts`

Добавить новые обработчики команд:

`**/law [запрос]**` -- поиск по таблице `laws`:

- Разбирает запрос (тип кодекса + номер/ключевое слово)
- Ищет по `title`, `short_title`, `content` с использованием `ilike`
- Возвращает первые 3 результата с кратким текстом

`**/profile**` -- информация об аккаунте:

- Запрашивает `profiles` + `user_roles` по `telegram_chat_id`
- Считает открытые тикеты из `support_tickets`
- Формирует красивое сообщение

`**/giveaways**` -- активные розыгрыши:

- Запрашивает `giveaways` со статусом `active`
- Показывает название, приз, дату окончания
- Добавляет ссылку на сайт

`**/tickets**` -- список тикетов:

- Запрашивает `support_tickets` для пользователя
- Показывает тему, статус, дату

`**/news**` -- последние новости:

- Запрашивает 5 последних записей из `discord_news`
- Показывает заголовок и краткое содержание

**Inline-кнопки** -- при `/start` без кода:

- Используется Telegram Bot API `sendMessage` с `reply_markup` (InlineKeyboardMarkup)
- Кнопки: "Поиск законов", "Розыгрыши", "Мои тикеты", "Новости", "Профиль"
- Добавить обработку `callback_query` в webhook

### Обработка callback_query

Webhook уже получает `callback_query` от Telegram при нажатии inline-кнопок. Нужно добавить:

- Проверку `update.callback_query` в дополнение к `update.message`
- `answerCallbackQuery` для подтверждения нажатия
- Маршрутизацию по `callback_data`

### Файлы которые будут изменены:

- `supabase/functions/telegram-bot/index.ts` -- добавление новых команд и inline-кнопок

Никаких изменений в базе данных не требуется -- все нужные таблицы уже существуют.||
